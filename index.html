Python API

三行代码，
让机械臂写下一个字

API 按"人类语言"设计——你要做什么，就叫什么名字。全部接口支持交互式教学与脚本化创作。

lesson_01.py — IDbot
# 1) 连接并归零（首次使用必做）
from idbot import IDbot

bot = IDbot(port="COM3", connect=True)
bot.home()                     # 归零 G27

# 2) 让它写字：起点 + 文字，就这么简单
bot.write_hanzi("你好世界", x=-80, y=200)

# 3) 让它走直线 / 画曲线
bot.move_line(x=200, y=150, z=50)
pos = bot.query_position()
print(pos.x, pos.y, pos.z)
connect() / home()连接、归零校准
write_hanzi(text, x, y)汉字书写 · 字号默认 30mm
move_abs(x, y, z)绝对定位（快速）
move_line(x, y, z)直线插补 · 轨迹为直线
move_inc(dx, dy, dz)相对增量运动
query_position()实时坐标查询
move_tool(s, t)腕部旋转 / 夹爪开合
set_speed(n) / estop()调速 · 急停
→ 完整接口见《使用高级手册》

Quick Start

三步，60 秒开动

不装环境、不配依赖、不查手册——先把机械臂动起来，再慢慢读文档。

01

下载解压

从 Release 下载发布包，解压到任意目录。自带字库与使用说明，无需 pip。

02

启动控制台

终端执行 python -m idbot web，浏览器打开 127.0.0.1:8080，选串口点连接。

03

回零，开玩

点【回零】，然后写字、画图、抓取四个页面随便切；写代码则 from idbot import IDbot。
